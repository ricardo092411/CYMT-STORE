# Logotipo CYMT STORE

## Cómo reemplazar el logo

Sustituye `logo-cymt.png` por el archivo oficial **sin cambiar el nombre ni
modificar código**. Toda la web lo usa automáticamente desde
`src/data/site.ts` → `site.logo.src`.

- Formato: PNG con fondo oscuro (la web es oscura, así se integra sin bordes).
- Proporción sugerida: horizontal (wordmark).
- Tamaño recomendado: ancho ~1000–1600px.
